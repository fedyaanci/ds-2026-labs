# Реализация PA3

- `Valuator` больше не вычисляет `rank`. Он сохраняет текст в Redis и отправляет
  в RabbitMQ сообщение только с идентификатором текста.
- Два экземпляра `RankCalculator` читают одну очередь как конкурирующие
  потребители. Каждое задание получает только один экземпляр.
- `RankCalculator` получает текст из Redis, вычисляет долю небуквенных символов
  и записывает `RANK-{id}`.
- Пока ключ результата отсутствует, Summary показывает
  «Оценка содержания не завершена».
- `docker-compose.yml` и PowerShell-скрипты запускают весь набор компонентов.

Запуск:

```powershell
.\scripts\start.ps1
```

Открыть `http://localhost:8080/`. Для просмотра очередей открыть
`http://localhost:15672/`, логин и пароль `lab`.
