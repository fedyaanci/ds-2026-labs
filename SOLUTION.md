# Реализация PA5

PA5 продолжает решение PA4 и добавляет доставку готового результата в браузер.

- `RankCalculator` перед расчетом ждёт случайное время от 3 до 15 секунд.
- В `Valuator` добавлен SignalR hub `/valuationHub`.
- Summary открывает WebSocket, входит в группу своего `textId` и ждёт событие.
- Каждый Valuator подписывается на `RankCalculated` через отдельную RabbitMQ
  очередь и отправляет результат своим SignalR-клиентам.
- При подключении hub дополнительно проверяет Redis. Поэтому готовый результат не
  потеряется, даже если событие возникло непосредственно перед подпиской браузера.
- Nginx настроен на проксирование WebSocket Upgrade.

Запуск:

```powershell
.\scripts\start.ps1
```

После отправки текста Summary сначала показывает сообщение об ожидании, а затем
обновляется без перезагрузки страницы.
